# Avito → Telegram

Бот пересылает новые входящие сообщения из мессенджера Авито в ваш Telegram.

## Настройка

1. **Ключи Авито.** Откройте https://www.avito.ru/professionals/api → «Получить доступ к API»
   и скопируйте `Client ID` и `Client Secret`.
   > Доступ к Messenger API есть не на всех тарифах Авито. Если бот получает ошибку 403 —
   > проверьте тариф / подключение API в личном кабинете.
2. **Telegram-бот.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
   Затем **напишите своему боту любое сообщение** (иначе он не сможет вам писать).
3. **Ваш chat id.** Напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш `Id`.
4. Скопируйте `.env.example` в `.env` и заполните значения.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Или в Docker:

```bash
docker build -t avito-tg-bot .
docker run -d --restart=always --env-file .env -v avito_bot_data:/data --name avito-tg-bot avito-tg-bot
```

После запуска в Telegram придёт «✅ Бот запущен», а дальше — каждое новое сообщение
с именем собеседника, объявлением и ссылкой «Ответить на Авито».

## Параметры (`.env`)

| Переменная | Описание |
|---|---|
| `POLL_INTERVAL` | Как часто проверять сообщения, сек (по умолчанию 30) |
| `MARK_AS_READ` | `true` — помечать чаты прочитанными на Авито после пересылки |
| `STATE_FILE` | Файл со списком уже пересланных сообщений (чтобы не было дублей) |

Бот должен работать постоянно (VPS, домашний сервер, Docker) — на компьютере,
который выключается, сообщения будут приходить только пока он включён.
