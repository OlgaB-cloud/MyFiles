# Avito → Telegram

Бот пересылает новые входящие сообщения из мессенджера Авито в ваш Telegram.

Есть два варианта:

- **`mail_bot.py` — через почту.** Для обычного (частного) профиля Авито. Бот читает письма
  Авито о новых сообщениях и пересылает их в Telegram. Запускается бесплатно на GitHub Actions
  каждые ~5 минут (`.github/workflows/avito-mail-to-telegram.yml`).
- **`bot.py` — через API Авито.** Для профессионального профиля с доступом к Messenger API.

## Вариант через почту (GitHub Actions)

1. В Авито включите уведомления о новых сообщениях на e-mail.
2. Яндекс Почта: **Настройки → Почтовые программы** → включите «С сервера imap.yandex.ru по протоколу IMAP».
3. Создайте пароль приложения: https://id.yandex.ru/security/app-passwords → «Почта».
4. Напишите своему Telegram-боту любое сообщение.
5. В GitHub: **Settings → Secrets and variables → Actions → New repository secret** добавьте:

   | Секрет | Значение |
   |---|---|
   | `MAIL_USER` | адрес почты, например `name@yandex.ru` |
   | `MAIL_PASSWORD` | пароль приложения из шага 3 (не обычный пароль!) |
   | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
   | `TELEGRAM_CHAT_ID` | необязательно: без него бот сам найдёт чат того, кто ему писал |

6. **Actions → Avito → Telegram → Run workflow** — первый запуск. В Telegram придёт
   «✅ Бот подключился к почте» и темы последних писем Авито. Дальше проверка идёт сама каждые ~5 минут.

Если приходят не все письма о сообщениях — добавьте переменную `MAIL_SUBJECT_FILTER`
(слова из темы письма через запятую, по умолчанию `сообщен,message`).
GitHub отключает расписание, если в репозитории 60 дней нет изменений, — тогда придёт письмо
от GitHub, и расписание нужно включить кнопкой в разделе Actions.

Запуск на своём компьютере/сервере: заполните `.env` (`MAIL_USER`, `MAIL_PASSWORD`, `TELEGRAM_*`)
и выполните `python mail_bot.py --loop`.

## Вариант через API Авито

### Настройка

1. **Ключи Авито.** Откройте https://www.avito.ru/professionals/api → «Получить доступ к API»
   и скопируйте `Client ID` и `Client Secret`.
   > Доступ к Messenger API есть не на всех тарифах Авито. Если бот получает ошибку 403 —
   > проверьте тариф / подключение API в личном кабинете.
2. **Telegram-бот.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
   Затем **напишите своему боту любое сообщение** (иначе он не сможет вам писать).
3. **Ваш chat id.** Напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш `Id`.
4. Скопируйте `.env.example` в `.env` и заполните значения.

### Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Или в Docker:

```bash
docker build -t avito-tg-bot .
docker run -d --restart=always --env-file .env -v avito_bot_data:/data --name avito-tg-bot avito-tg-bot
```

После запуска в Telegram придёт «✅ Бот запущен», а дальше — каждое новое сообщение
с именем собеседника, объявлением и ссылкой «Ответить на Авито».

### Параметры (`.env`)

| Переменная | Описание |
|---|---|
| `POLL_INTERVAL` | Как часто проверять сообщения, сек (по умолчанию 30) |
| `MARK_AS_READ` | `true` — помечать чаты прочитанными на Авито после пересылки |
| `STATE_FILE` | Файл со списком уже пересланных сообщений (чтобы не было дублей) |

Бот должен работать постоянно (VPS, домашний сервер, Docker) — на компьютере,
который выключается, сообщения будут приходить только пока он включён.
